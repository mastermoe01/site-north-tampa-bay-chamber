# site-north-tampa-bay-chamber

Demo website for the North Tampa Bay Chamber (Wesley Chapel, FL), built by Raqm AI & Automation.

- Next.js 16 App Router + Tailwind 4, React Three Fiber (hero: the chamber's four-ribbon mark in 3D), Framer Motion.
- Content is taken verbatim from northtampabaychamber.com and the chamber's Google Business Profile (captured 2026-11-11).
  Membership, events, directory and contact CTAs link to the chamber's existing GrowthZone system.
- Video slot: `public/videos/28329-paseo-dr/{walkthrough,flyover}.mp4` (+ `poster-*.jpg`) appears on /about when present.

```bash
npm install
npm run dev
```
